# 阶段 4 暴露点：分润 + 延迟结算

**日期**：2026-09-17 ｜ **复杂点**：事件驱动分润 · T+N 结算 · 退款回滚 · 防刷

## 场景边界

| 在范围内 | 不在范围内 |
| :--- | :--- |
| L1/L2 订单抽成规则 | 商城域优惠券 |
| 推广关系绑定 + 补贴 | 信用/先用后付 |
| ORDER_COMPLETED 触发分润意向 | 实时打款到银行卡 |
| T+7 SettlementBatch | 税务/牌照合规细节 |
| 退款撤销未结算分润 | 直播/社区 |

## 暴露点

| # | 检验什么 | 预期 KB |
| :-- | :--- | :--- |
| **P4-1** | 分润在 ORDER_COMPLETED，非 PAID | design-decision |
| **P4-2** | 分润意向与结算分离（延迟 T+7） | A4 可观测触发 |
| **P4-3** | ProfitShareAccrual 追加-only，退款写 reversal | base-contract |
| **P4-4** | 组织树多级百分比之和 ≤ 100% | A3 主动侦查 |
| **P4-5** | 推广绑定有效期 + 唯一性 | 防刷策略写规格 |
| **P4-6** | SettlementBatch 汇总可对账 | reproducible-verification |

## 已裁决（tick 1）

| 项 | 裁决 |
| :--- | :--- |
| 触发事件 | **ORDER_COMPLETED**（权益可撤销窗口后再分润） |
| 结算周期 | **T+7** 批处理 |
| 推广绑定 | 用户注册后 **72h** 内绑定，过期不可补绑 |
| L1/L2 分成 | L2 10% · L1 5% · 平台余量（示例规则，可配置） |

## 成功标准

1. 订单完成 → 产生 Accrual；7 天后 Batch 结算入账
2. 结算前退款 → Accrual reversal，Batch 不包含该笔
3. 规格层完成，无运行时代码
