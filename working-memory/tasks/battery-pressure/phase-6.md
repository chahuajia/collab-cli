## 已裁决（tick 1）

| 项 | 裁决 |
| :--- | :--- |
| 账单周期 | **自然月**，T+1 日出账 |
| 还款宽限期 | **7 天**，逾期第 8 天冻结 |
| 额度模型 | 平台授予 `creditLimit`，`usedCredit` 实时累计 |
| 适用 | 仅 FIXED_PRICE 换电 Product（非 P3 按量后付） |

## 成功标准

1. 信用用户 0 余额可购月卡，产生账单
2. 还款后 usedCredit 下降，可再购
3. 逾期不可 swap
4. 规格完成，无运行时代码
